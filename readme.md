## 🎨 The Evolution Of Forum Design

Invision Community (IPS) is a powerful forum software, but its default themes often feel stuck in the past. They are functional, but they lack the sleek, dynamic feel of modern web applications. For community managers who want to stand out, the default look is simply not enough.

**IPS Community Dynamic Theme** is a premium-quality, open-source theme designed to drag your forum into the modern era. It is not just a color swap; it is a complete visual overhaul. It features glassmorphism panels, smooth micro-animations, and a responsive layout that looks stunning on both 4K monitors and mobile phones.

This repository provides the complete XML theme file, the custom CSS, and the JavaScript extensions needed to install it. It includes built-in support for dark mode, a dynamic header that shrinks on scroll, and a redesigned user profile card. It is the ultimate theme for gaming communities, tech forums, and creative hubs that want to make a bold first impression.

## 🧠 Under The Hood: The Architecture Of A Theme

Building a theme for IPS is not like building a WordPress theme. IPS uses a complex templating system with its own CSS preprocessor.

Our theme is built on top of the **IPS UI Kit**. Instead of modifying the core templates (which would break on updates), we use the built-in **CSS Variables** and the **Theme Editor**. This means you can update your IPS forum without losing your custom design.

The dynamic header is powered by a lightweight JavaScript file. It listens to the scroll event and uses `requestAnimationFrame` to smoothly transition the header's height and opacity. It is highly optimized to avoid layout thrashing, ensuring your forum remains buttery smooth even on low-end devices.

## ⚙️ Getting Started

To install the theme, you will need access to your IPS Admin Control Panel (ACP).

```bash
# Step 1: Download the theme XML file from the releases page
# Step 2: Log in to your IPS Admin Control Panel
# Step 3: Navigate to Customization -> Themes -> Upload New Theme
# Step 4: Upload the XML file and click "Save"
# Step 5: Set the theme as the default for your community
```

Once installed, navigate to the Theme Settings to customize your colors. We have included a palette of pre-set color schemes (Ocean, Sunset, Midnight) that you can apply with a single click.
